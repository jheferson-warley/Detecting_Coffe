# 📊 Detecting Coffee Bean Maturity using Deep Learning

Este projeto foi desenvolvido como parte do Trabalho de Deep Learning da Pós-graduação em Ciência de Dados e Machine Learning. O objetivo é classificar imagens de grãos de café de acordo com seu nível de maturação utilizando técnicas de **Deep Learning** e **Transfer Learning** com a arquitetura **DenseNet121**.

## ☕ Contexto

A classificação precisa do nível de maturação dos grãos de café é um desafio importante na cadeia produtiva do agronegócio. Uma solução automatizada baseada em visão computacional pode trazer mais agilidade e precisão ao processo de seleção, impactando positivamente a qualidade final do produto.

---

## 🎯 Objetivos

- Classificar imagens de grãos de café em diferentes estágios de maturação.
- Utilizar Transfer Learning com DenseNet121.
- Avaliar o desempenho do modelo com métricas adequadas.
- Discutir melhorias e aplicações futuras.

---

## 🧠 Técnicas Utilizadas

- **Transfer Learning** com `DenseNet121`
- Fine-tuning da rede neural
- Pré-processamento com `ImageDataGenerator`
- Regularização com `Dropout` e `EarlyStopping`
- Avaliação com **matriz de confusão**, **acurácia**, **sensibilidade**, **especificidade** e **curva ROC**

---

## 🛠 Tecnologias

- Python 3.10+
- TensorFlow & Keras
- Pandas
- Matplotlib & Seaborn
- Jupyter Notebook

---

## 📊 Resultados
- Modelo final com alta acurácia na validação.
- Boa generalização mesmo com um conjunto de dados limitado.
- Curva ROC indicou forte capacidade de discriminação entre classes.
- Base sólida para futura implantação em sistemas embarcados ou aplicações móveis no setor agroindustrial.
